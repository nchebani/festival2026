Studio — projets et pistes

Chaque membre dépose ses enregistrements dans son dossier ; tous peuvent les récupérer et continuer à travailler.

Bien déposer un projet Ableton Live
  1. Dans Ableton : Fichier > Réunir et Sauvegarder, pour que tous les samples soient copiés dans le dossier du projet.
  2. Compresse le dossier du projet (clic droit > Compresser).
  3. Dépose le .zip, ou donne un lien si le fichier est très gros.
  4. Marque ton dépôt « Terminé » quand tu as fini, les autres repartent de ta dernière version.

Réceptions — liens à télécharger

SwissTransfer, WeTransfer, Drive… Déposez le lien, chacun coche quand il a téléchargé.

Ces liens expirent : la durée dépend du service et de l’offre. Pour garder un fichier longtemps, déposez-le plutôt dans le Studio.
